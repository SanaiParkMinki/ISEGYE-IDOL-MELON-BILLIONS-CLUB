# 이세계아이돌 멜론 누적 스트리밍 집계 사이트

사이트: https://sanaiparkminki.github.io/ISEGYE-IDOL-MELON-BILLIONS-CLUB/

곡별 누적 스트리밍 수를 `data/input.txt`에 저장하면 **1~2분 안에** GitHub가 알아서

- 이세계아이돌 그룹 명의 38곡(Inst. 포함) 합계와 고세구 《NO CAT, NO LIFE!》 3곡 합계를 계산하고
- 날짜별로 기록하고 (하루에 하나, 같은 날 다시 저장하면 마지막 숫자로 바뀜)
- 사이트와 디스코드 알림을 새로 고칩니다.

| 파일 | 하는 일 |

## 매일 할 일 (숫자 입력)

1. 사이트에서 **✏️ 숫자 입력 도우미**를 열어요.
2. 곡마다 누적 감상 수를 넣어요. 곡 이름 옆 **가이섬 ↗**을 누르면 그 곡 기록이 바로 열려요.
   - 바뀌지 않은 곡은 비워 두면 이전 숫자를 그대로 써요.
   - 숫자가 이상하면 칸이 빨간색(줄어듦)이나 노란색(너무 많이 늘어남)으로 바뀌어요.
3. **📋 복사** → **GitHub에서 열기** → 편집 칸에서 **Ctrl+A → Ctrl+V** → **Commit changes**
4. 1~2분 뒤 사이트와 디스코드에 반영돼요.

## 실수 막기

- 이전 기록보다 **줄어든 곡**이 있으면 기록하지 않고 멈춰요 (Actions 빨간불). 실행 기록의 "합계 계산" 단계를 열면 어느 곡인지 나와요.
- 멜론이 실제로 숫자를 정정한 거라면: **Actions → 누적 합계 갱신 → Run workflow → "줄어든 숫자도 그대로 기록" 체크 → 실행**
- 하루에 5% 넘게 늘어난 곡은 경고만 하고 기록은 해요.

## 디스코드 자동 알림 설정 (처음 한 번만)

1. 디스코드에서 알림 받을 채널의 ⚙️ **채널 편집 → 연동 → 웹후크 → 새 웹후크** → **웹후크 URL 복사**
2. GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `DISCORD_WEBHOOK_URL`
   - Secret: 복사한 주소 붙여넣기 → **Add secret**
3. 다음에 숫자를 저장하면 알림이 와요. (설정 안 하면 알림만 건너뛰고 나머지는 그대로 동작)

> 웹후크 주소는 비밀번호 같은 거라 다른 곳에 올리지 마세요.

## 곡 추가하기

새 곡이 나오면 `data/input.txt`에 `이세계아이돌 | 곡 제목 | 숫자` 줄을 하나 더 쓰고 저장하면 돼요.
멜론 링크·앨범 표시까지 원하면 `data/songs.json`에도 같은 제목으로 추가하세요.
새 그룹 이름(예: `릴파`)을 쓰면 사이트에 칸이 하나 더 생겨요.

## 알아두면 좋은 점

- 숫자를 안 넣은 날은 건너뛰어요. 다음 기록의 증가량은 "N일치"로 표시하고 하루 평균으로 나눠 보여 줘요.
- 저장 단계에서 권한 오류(403)가 나면: **Settings → Actions → General → Workflow permissions → Read and write permissions** 선택 후 저장.
- 압축 파일을 통째로 다시 올릴 땐 `data/history.json`, `data/input.txt` 를 ✕로 빼고 올리세요.
